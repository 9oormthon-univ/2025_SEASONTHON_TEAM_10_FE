### 설치 및 실행

```bash
# 의존성 설치
yarn install

# 개발 서버 시작
yarn start

# iOS 시뮬레이터에서 실행
yarn ios

# Android 에뮬레이터에서 실행
yarn android

# 웹에서 실행
yarn web
```
